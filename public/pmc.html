口径（按 PRD 3.1 / 3.2 实现；括号里是仍需你确认的假设）
  1. 日末理论库存 = 月初库存 − 当日客户订单消耗（逐日滚动）。只看消耗，未含到货；原表那行「库存」在②里做对照。
  2. 触发线 = SNP × 保留倍数；理论库存 < 触发线 的第一天 = 缺料日。
  3. 覆盖区间 = [缺料日, 缺料日 + 缺口天数 − 1]；覆盖需求 = 该区间需求合计。
  4. 建议下单量 = 覆盖需求 + 触发线 − 到货时库存，再按包装倍数向上取整、不足 MOQ 提到 MOQ。
  5. 建议下单日 = 缺料日 − 提前期；运输方式「自提」再向前挪到最近的周一/周四；「集中送货」同普通但下单量受 MOQ 约束。
  6. 加工周期（工作日）：材料不能卡在缺料那天到货 —— 先算最晚到货日（缺料日往前退 N 个工作日），再算下单日（到货日 − 提前期）。到货当天不算加工，从次日开始数；周末跳过，节假日按「参数」页填的清单跳过。
    例：6/19(周五) 缺料、加工 3 个工作日 → 最晚 6/16(周二) 到货，6/17·18·19 加工完正好覆盖。提前期 3 天 → 6/13 下单。
  7. 下单量仍按 PRD 3.2：覆盖需求 + 触发线 − 缺料日当天日末库存（到货提前了，但到货到加工完这段时间的消耗由现有库存承担，所以数量口径不变）。
  8. SNP / 月初库存从主表里自动读（「SNP 40」这类文字）；缺口天数、提前期、运输方式、MOQ、包装倍数主表里没有，默认值 + 你在表里手改。
